# S5-1 判据（先落盘再运行）

## 范围
- 设备列表（原子写）
- 多会话并发 + 会话角色（控制者/观看者）
- 屏幕墙低码率子码流（不额外创建编码实例）
- `demo-wall`：1 host + 3 viewer，各拉一路子码流，运行 10 s

## 实现选择（子码流）
**选项 B：一个共享的缩略图编码器**（单个 MF H.264 实例，480p / 10 fps / 低码率），
输入来自采集帧的最近邻缩放；**不是**每路一个编码实例，也不是「从主编码器输出缩放」。
代价见 `crates/rdc-core/src/s5/wall.rs` 模块注释与 D41。

## demo-wall 判据（10 s 窗口）
| # | 判据 | 门槛 | 数据来源 |
|---|---|---|---|
| W1 | 每路预览帧率 | ≥ 5 fps | 每 viewer 逐帧 CSV 计数 / 10 s |
| W2 | 帧时间戳单调 | 严格递增 | 逐帧 CSV `pts_us` |
| W3 | 端到端预览延迟 p99 | ≤ 500 ms | 逐帧 CSV `latency_us`（接收时刻 − 帧时间戳） |
| W4 | host 额外 CPU | 有实测数字 | GetProcessTimes：主码流-only 阶段 vs 主码流+屏幕墙阶段 |
| W5 | 4 路预览额外 CPU | ≤ 单路主码流的 30% | 3 路实测额外 CPU 按 fanout 线性外推 4 路 |
| W6 | 无未响应 | 所有网络操作有超时，超时计数 0 | host/viewer 超时计数 |
| W7 | 退出无残留 | 单进程、无子进程/窗口，会话全部 close | 进程与日志 |

## 设备列表判据
- D1 保存→加载往返一致（JSON，字段齐全）。
- D2 缺失文件按空列表处理；损坏 JSON 返回错误而不 panic。
- D3 `upsert_online` 更新最后在线与名称，**保留**本地信任位。
- D4 原子写：目标文件旁边的 `.tmp` 不存在；写入中途崩溃不会留下半截目标文件（rename 语义）。

## 多会话判据
- M1 capabilities 置 bit10（多会话）/ bit11（屏幕墙）/ bit7（子码流）；与旧对端协商后按位与被丢弃。
- M2 观看者注入输入被拒绝（`viewer_readonly`），控制者允许。
- M3 会话注册表达到 `max_sessions` 后拒绝新会话；释放后可再注册。
- M4 并发 3 路观看者会话可共存（demo-wall 实际建链验证）。
