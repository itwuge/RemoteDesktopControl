| 版本 | v0.1（2026-11-08） |
| 关联 | `.gitignore`、`docs/19-错误码与自助诊断.md`、`product/07-已知限制与验证状态.md` |

## 1. 什么入库、什么不入库

| 类别 | 是否入库 | 说明 |
|---|---|---|
| `TESTPLAN-*.md`、结论/报告类 `.md` | **入库** | 判据、条件、结论、数字必须可追溯 |
| 原始运行日志 `*.log` | 不入库 | 体积大、含本机路径与环境噪声；按第 3 节定位索取 |
| 抓帧、录屏、`*.y4m`、`*.bmp`、`*.png` 序列 | 不入库 | 体积大；测试结论里写清样本量与窗口即可 |
| dump、`*.jsonl` 原始事件流 | 不入库 | 涉及本机会话数据；必要时脱敏后摘录进 `.md` |
| 安装包、构建产物 | 不入库 | 见 `.gitignore`；发布件另走交付渠道 |

规则：**判据与结论必须入库；原始产物可外置，但必须有定位信息。** 一份 TESTPLAN 如果只有结论、没有执行日期/机器/原始日志定位，视为不合格。

## 3. 原始产物在哪、怎么索取

- 原始日志与抓帧**不随仓库分发**，只留在执行机本地（`logs/` 工作目录或测试临时目录），当前未回传、未登记大小。
- 索取方式：向执行人/指挥提供**任务号**（如 `s7-8`）与 TESTPLAN 头部登记的文件名，由执行人回传；回传后建议同步更新该 TESTPLAN 头部的路径与大小。
- 长期存放位置尚未确定（网盘/共享盘），待指挥统一安排；在此之前以执行机为准。
