## 0. 测试纪律

1. **判据先行**：本文件就是判据。执行前不得改数字、不得删步骤；要改先改 02 号文档并升版本。
2. **必须留证**：每个用例留“截图/录屏 + 日志片段 + 命令输出”三选二；只写“已测通过”不算证据。
3. **不测无目的项**：每个用例都要能回答“失败时说明哪条需求没做到”。
4. **不改环境蒙混**：不允许通过关闭安全软件、放宽超时、跳过确认弹窗来让用例通过；环境不满足就记 BLOCKED。
5. **结果可解释**：失败要写清“实际观察值 vs 判据值”，不写“感觉不行”。

## 1. 环境与准备

| 项 | 要求 |
|---|---|
| A 机（主控） | Windows 10/11 x64，干净用户目录，未登录账号 |
| B 机（被控） | Windows 10/11 x64，干净用户目录；另备一台 Windows 家庭版（或用虚拟机）用于 T-29 |
| 网络 | ① 同交换机有线/同一 Wi-Fi；② 手机热点跨网；③ 可物理断网（拔网线/禁用网卡） |
| 构建 | 当前版本安装包；另备**上一版本**客户端（用于 T-28 的 N-1 兼容） |
| 工具 | PowerShell、`Get-NetTCPConnection`、`Get-FileHash`、`powercfg /requests`（管理员）、抓包工具（可选） |
| 数据 | 1GB 测试文件（可用 `fsutil file createnew` 生成）、2MB+ 文本、10MB+ 图片、含 `..\` 的非法路径样本 |
| 记录 | 每轮测试建一个目录，按 `T-编号/证据` 存放；路径由测试执行人按 `docs/10` 的日志规范落盘，本文件不指定写盘位置 |
| Windows 签名状态 | **未签名**（无代码签名证书）。首次运行预期出现 SmartScreen「未知发布者」；按 `product/04-发布与签名口径.md` 的「更多信息 → 仍要运行」执行，并截图留证。这是有效测试环境，不是缺陷 |
| Windows 企业策略环境 | 若被 AppLocker / WDAC / 组策略 / 终端安全软件拦截，记 **BLOCKED（环境限制）**，换非受管机器复测；不算产品缺陷，也不允许通过关闭安全策略来“通过”用例 |
| macOS（本地验证） | 未公证、ad-hoc 签名。首次打开需右键「打开」，或执行 `xattr -dr com.apple.quarantine /Applications/RDC.app`；该环境仅用于本地验证，不作为对外支持范围 |
| iOS | **只在模拟器运行**；模拟器为有效环境。iOS 真机无法安装，记 **N/A（不在支持范围）**，不计 PASS/FAIL，不提供真机安装步骤 |
| Android（正式目标，当前内部环境） | **定位**：正式控制端，按正式标准开发与验收（D45）。**当前环境**：只有 **debug 签名 APK**，真机需允许「安装未知来源」或 `adb install -r`；该环境属内部环境验证，不代表对外发布。不上架、不承诺正式签名与覆盖升级 |

> 环境判定口径：未签名 Windows = 有效；企业策略拦截 = BLOCKED；macOS 未公证 = 有效（仅本地验证）；iOS 模拟器 = 有效、iOS 真机 = N/A；Android debug 真机 = 有效（**内部环境**；Android 定位为正式控制端，见 `docs/决策待办.md` D45）。详细依据见 `product/04-发布与签名口径.md`，两份文档不得出现相反结论。

> 所有涉及“秒”的判据，用秒表或录屏时间轴核对；所有涉及日志字段的判据，直接贴日志原文，不转述。

## 2. 逐需求用例

### T-01 首屏两个主动作（R-01，P0）

- **前置**：A 机全新用户目录，首次启动。
- **步骤**：截首屏；数一级可点入口；请 5 名未读过文档的人各自找“让别人连我”的入口；逐个悬停顶部图标。
- **判据**：一级入口 ≤6；UI 文案无“场景/返回旧版/投屏/应用中心/福利”；5 人中 ≥4 人在 60 秒内找对；每个图标 1 秒内出中文说明。
- **证据**：首屏截图、5 人点击路径记录、图标悬停截图。

### T-02 一键邀请（R-02，P0）

- **前置**：B 机已开启“允许被连接”，A 机在连接页。
- **步骤**：点「复制邀请」；在 A 机粘贴整段；刷新临时密码；用旧密码再连；改别名并重启。
- **判据**：剪贴板含设备码/临时密码/有效期三字段且整段可解析；刷新前有确认；旧密码连接被拒且审计含 `pair_code_rejected`；二维码与邀请串逐字一致；别名重启后保留。
- **证据**：剪贴板原文、解析后界面截图、拒绝提示、审计片段、二维码解码结果。

### T-03 免账号连接（R-03，P0）

- **前置**：两台机器全新用户目录，**不登录任何账号**。
- **步骤**：A→B 发起连接；生成一次性邀请码后等待 10 分钟再连；禁用外网仅留局域网，用已信任设备再连。
- **判据**：不登录可完成连接；10 分钟后提示“邀请已过期”且拒绝；断外网后信任设备仍可连；无强制登录弹窗。
- **证据**：连接成功截图、过期提示、断网连接日志。

### T-04 首启默认拒绝（R-04，P0）

- **前置**：B 机全新安装，未动任何开关。
- **步骤**：A 机发起连接；B 机首次打开“允许控制本设备”；查看弹窗；关闭开关后再连。
- **判据**：未操作时 100% 被拒且审计含 `access_denied_default`；首次打开必出说明弹窗，未确认不生效；关闭后 ≤2 秒拒绝新连接。
- **证据**：拒绝截图、审计、弹窗截图、时间轴。

### T-05 连接前确认卡片（R-05，P0）

- **前置**：B 机允许被连接；A 机持有效邀请。
- **步骤**：A 发起；B 观察弹窗 15 秒不操作；再次发起并点拒绝；第三次勾选“记住此设备”后再连。
- **判据**：弹窗含对方别名/权限/有效期/路径四字段；15 秒超时拒绝且审计含 `request_timeout`；拒绝有回执；记住后第二次不弹窗。
- **证据**：弹窗截图、超时与拒绝审计、回执截图、第二次连接截图。

### T-06 连接后能力与工具栏（R-06，P1）

- **前置**：B 机给 A 机“只观看”授权。
- **步骤**：检查连接对话框有无模式单选；连入后数工具栏按钮；尝试键盘鼠标；点“更多”里的切换显示器。
- **判据**：无四种模式单选；默认可见动作 ≤5；只观看下输入被拒且按钮灰显并说明原因；危险动作需二次确认。
- **证据**：对话框截图、工具栏截图、输入被拒日志、确认弹窗截图。

### T-07 信任设备管理（R-07，P1）

- **前置**：至少 2 台设备已加入信任表。
- **步骤**：新增一台；查看排序与时间；加备注；删除其中一台后重连。
- **判据**：新增/删除 1 秒内列表更新；按最近连接倒序、时间本地时区到分钟；删除后必须重新确认且审计含 `trust_removed`。
- **证据**：列表截图、删除前后审计。

### T-08 关闭/退出三选一（R-08，P0）

- **前置**：B 机允许被连接，A 机保持连接中。
- **步骤**：点关闭；分别选“取消”“托盘”“退出”；再在有会话时选退出；核对进程与端口。
- **判据**：首次必出三选项；退出后 3 秒内进程退出、无监听（`Get-NetTCPConnection` 输出为空）、审计含 `app_exit`；托盘模式窗口消失但可被连；有会话时退出出现“将断开 N 个会话”确认。
- **证据**：三选项截图、进程/端口命令输出、审计、托盘提示截图。

### T-09 状态条三态（R-09，P0）

- **前置**：B 机开关关闭；A 机待命。
- **步骤**：观察关闭态；开启但无人连接；A 连入；关闭开关。
- **判据**：三态文案与颜色正确；连入后 1 秒内显示控制者/权限/人数；每次变化有日志；关闭态不出现“可被连接”。
- **证据**：三张状态截图、时间轴、日志片段。

### T-10 一键停止（R-10，P0）

- **前置**：A、B 已建立 2 个会话（1 控制 + 1 观看）。
- **步骤**：B 点「立即停止远程访问」并确认；观察 A 端；核对审计；再次发起连接；重新开启开关。
- **判据**：≤2 秒全部会话断开；A 端提示“对方已停止远程访问”；审计含 `access_stopped` 与断开会话数；停止后连接被拒；重新开启需再次确认。
- **证据**：两端录屏/截图、审计、时间轴、重开确认截图。

### T-11 权限三档与有效期（R-11，P0）

- **前置**：B 机新建授权。
- **步骤**：查看三张卡片；不改默认直接保存；等待有效期到期；用完全控制档触发重启/关机。
- **判据**：每档有一句白话说明；默认“只观看”、30 分钟；到期 ≤2 秒断开/降级且审计含 `grant_expired`；敏感操作逐次确认，无确认则被拒并记录。
- **证据**：卡片截图、默认值截图、到期提示、操作被拒日志。

### T-12 授权列表与吊销（R-12，P1）

- **前置**：B 机有 2 条有效授权，1 台在线。
- **步骤**：查看列表字段；吊销在线那台；观察 A 端；查看空状态。
- **判据**：新授权 1 秒内出现且五字段齐全；吊销后 ≤2 秒断开、A 端提示“授权已被吊销”、审计含 `grant_revoked`；空状态有添加说明。
- **证据**：列表截图、A 端提示、审计、空状态截图。

### T-13 第二人接管（R-13，P0）

- **前置**：B 机接管策略为默认“需本机确认”；A 已控制。
- **步骤**：C 发起第二会话；B 不操作等 15 秒；C 再发起，B 确认；改“允许”后再试。
- **判据**：默认档弹窗含 C 身份与权限；超时拒绝且原会话不受影响、审计含 `takeover_timeout`；确认后按选择降级/断开原控制者、审计含 `takeover`；“允许”档人数从 1 变 2。
- **证据**：弹窗截图、两端状态、审计、人数变化截图。

### T-14 审计可查（R-14，P1）

- **前置**：依次完成连接、授权、接管、踢出、停止。
- **步骤**：打开「最近活动」；核对五类事件字段；复制记录；清空。
- **判据**：五类事件齐全，字段含本地时间/对方别名/权限/动作/结果；复制内容为纯文本且无媒体字段；清空需二次确认并新增 `audit_cleared`。
- **证据**：列表截图、复制文本、清空前后截图。

### T-15 通知只报事件（R-15，P1）

- **前置**：通知开启。
- **步骤**：触发上线、连接、传文件、授权变更各一次；关闭通知后再触发；检索 UI 文案。
- **判据**：只有四类通知；连接开始 1 秒内出现且含别名/权限；关闭后不再产生通知；文案无“福利/活动/礼包/折扣/会员”。
- **证据**：通知截图、关闭后截图、文案检索结果。

### T-16 失败提示可行动（R-16，P0）

- **前置**：准备四种失败条件（对方离线、对方拒绝、跨网无法直连、旧版本不支持）。
- **步骤**：逐类制造失败；点「复制诊断」；检查文案。
- **判据**：四类均有白话原因 + 下一步 + 错误码 + 复制诊断；截图无 `panic/Exception`/英文堆栈；复制内容含时间/版本/平台/错误码/最近 5 条事件，且不含临时密码或令牌。
- **证据**：四张错误卡片截图、复制文本、脱敏核对记录。

### T-17 断线重连（R-17，P0）

- **前置**：A、B 已建立会话。
- **步骤**：拔网线 5 秒后恢复；观察界面；断开 11 分钟后再试；检查重连期间界面。
- **判据**：10 秒内自动恢复画面并显示“重连 1/3”；10 分钟内恢复后权限与画面延续；超 10 分钟提示“会话已结束”且可一键重连；期间无白屏/崩溃。
- **证据**：录屏、HUD/日志重连次数、超时提示截图。

### T-18 HUD 指标（R-18，P1）

- **前置**：A、B 同交换机有线。
- **步骤**：建立会话，读 HUD 三次；分别以仅直连、开启中继运行；关闭再打开 HUD。
- **判据**：HUD 含延迟/帧率/码率/路径/分辨率；直连延迟 ≤30ms（三次采样记录）；路径字段两配置正确；关闭无残留、重开 1 秒内出现。
- **证据**：HUD 截图三张、路径截图、日志数值。

### T-19 画质与帧率上限（R-19，P1）

- **前置**：B 机硬件探测上限为 60fps（记录探测值）。
- **步骤**：查看默认模式；选 120 帧保存；切档位；恢复默认。
- **判据**：默认“自动”；120 被夹到 60 并说明原因，日志含原值/生效值；切档后 3 秒内 HUD 变化；恢复默认一键完成。
- **证据**：设置截图、夹取提示、日志、HUD 前后截图。

### T-20 缩放与多屏（R-20，P1）

- **前置**：A 机支持 125/150/200% 缩放；B 机双屏。
- **步骤**：逐档缩放重启客户端，逐页截图；选择屏 1/屏 2；检查鼠标缩放。
- **判据**：三档无截断/重叠；1.25 倍正文清晰；切换屏 3 秒内更新；鼠标缩放开关有效。
- **证据**：九张逐页截图（三档 × 三页）、双屏切换录屏。

### T-21 中继默认关（R-21，P0）

- **前置**：默认配置，未填中继地址。
- **步骤**：发起连接并抓包/查日志；打开中继（确认弹窗）；跨网打洞失败时观察提示。
- **判据**：默认无任何到中继地址的连接；开启需确认且 HUD 显示“中继”；关闭时失败提示“未开启中继，无法直连”，无静默尝试。
- **证据**：抓包/日志、确认弹窗截图、失败提示截图。

### T-22 文件传输（R-22，P1）

- **前置**：准备 1GB 文件与非法路径样本。
- **步骤**：传输并观察进度；中途断网再恢复；尝试 `..\` 路径；完成后核对哈希。
- **判据**：进度/速度/剩余时间每 500ms 更新；完成后哈希一致；续传从已有 offset 开始；非法路径被拒并审计。
- **证据**：进度截图、哈希命令输出、续传日志、拒绝提示。

### T-23 剪贴板（R-23，P1）

- **前置**：新会话默认配置。
- **步骤**：复制文本；开启剪贴板后再复制；复制 2MB+ 文本；复制敏感格式内容。
- **判据**：默认不同步且有开启入口；开启后 1 秒内同步；超限提示“内容过大”；敏感格式不发送且审计含 `clipboard_skipped`。
- **证据**：两端截图、超限提示、审计片段。

### T-24 屏幕墙（R-24，P1）

- **前置**：B 机未添加任何设备。
- **步骤**：查看空状态；添加 9 台；观察预览；点击一路进入；连续操作 1 分钟。
- **判据**：空状态有说明与「添加设备」；5 秒内出预览；预览 480p/5fps（日志可证）；点击 3 秒内进主码流；9 路时无未响应。
- **证据**：空状态截图、预览参数日志、进入耗时、性能观察记录。

### T-25 快捷键（R-25，P2，后置）

- **前置**：v1 不执行；R-25 排期后执行。
- **步骤**：验证 5 个快捷键；设置冲突组合；恢复默认。
- **判据**：5 个生效；冲突保存被拒并指出冲突项；恢复默认可用。
- **证据**：设置截图、冲突提示。

### T-26 无人值守开关（R-26，P1）

- **前置**：管理员权限。
- **步骤**：查看默认值；开启自启后重启；开启防休眠并保持会话；关闭两项后查残留。
- **判据**：两项默认关；重启登录后 30 秒内进程存在；会话中 `powercfg /requests` 有对应请求、结束后消失；关闭后无计划任务/服务残留。
- **证据**：默认值截图、命令输出、powercfg 前后输出。

### T-27 设置页（R-27，P0）

- **前置**：默认配置。
- **步骤**：检查布局与分组；逐项找术语说明；输入非法中继地址；恢复默认；抽查 5 项重启保留。
- **判据**：无左右分栏、分组 ≤7、术语有 ≤20 字说明；非法值被拦；恢复默认生效并写日志；5 项重启后保留。
- **证据**：设置页截图、非法输入提示、重启前后截图、日志。

### T-28 更新与 N-1 兼容（R-28，P0）

- **前置**：当前版本 + 上一版本客户端；断网环境。
- **步骤**：检查更新（断网/联网）；用旧版连新版；查看差异提示。
- **判据**：断网提示“无法检查更新”无堆栈；旧版可连新版；差异能力显示“对方版本不支持 XX”；无按版本拒绝连接的逻辑。
- **证据**：更新提示截图、互连截图、差异提示、服务端配置核对。

### T-29 安装预期与平台范围（R-29，P0）

- **前置**：Windows 家庭版环境；未签名安装包。
- **步骤**：安装并读第一屏；查看启动页平台说明；在家庭版尝试被控。
- **判据**：安装向导含“未知发布者”预期与 `Get-FileHash` 步骤；平台范围写明；家庭版提示“此系统不支持被控”；无“即将支持”可点入口。
- **证据**：安装截图、启动页截图、家庭版提示截图。

### T-30 卸载干净（R-30，P1）

- **前置**：已安装并运行过，含自启与会话记录。
- **步骤**：卸载；分别验证“保留配置”和“清除”；核对进程/服务/自启/端口。
- **判据**：卸载后三项（进程/服务/自启）均不存在、端口无监听；保留/清除行为符合选择；清除密钥有二次确认。
- **证据**：命令输出、目录截图、确认弹窗截图。

### T-31 零付费零营销（R-31，P0）

- **前置**：未登录、无任何付费状态。
- **步骤**：全局检索 UI 文案；连续运行 24 小时抓包；逐项走查 v1 功能。
- **判据**：文案检索“会员/福利/礼包/折扣/续费/额度”零命中；24 小时无营销/统计域名请求；全部 v1 功能可用。
- **证据**：检索命令输出、抓包摘要、功能走查表。

### T-32 新手引导（R-32，P2，后置）

- **前置**：v1 不执行；R-32 排期后执行。
- **步骤**：首次启动看清单；点跳过；完成首次连接；从帮助重开。
- **判据**：3 步清单出现；跳过后来不再自动出现；完成后自动标记；无未完成红点。
- **证据**：清单截图、跳过前后截图。

### T-33 原生保底窗口（R-33，P0）

- **前置**：复现机（AMD RX 580 2048SP + Flutter 3.47.9）；另备一台可禁用显卡驱动的机器。
- **步骤**：① 在复现机双击启动，秒表计时到保底窗口出现；② 禁用显卡驱动后启动；③ 点三个按钮各一次；④ 点「用兼容渲染重试」；⑤ 检查设置页渲染状态。
- **判据**：≤3 秒出现保底窗口，含 `RDR-001` + 一句中文原因 + 三个按钮；两种故障路径均不出现超过 3 秒的纯白；「复制诊断」为纯文本，含错误码/时间/版本/平台/GPU 型号与驱动版本/最近 5 条事件，且不含密码、令牌、配对码；「打开日志目录」打开真实目录且存在本次日志；「兼容渲染重试」≤10 秒进主界面，设置页显示「当前渲染：兼容模式」；重试仍失败时窗口保留、不退回纯白。
- **证据**：启动录屏（带秒表/时间轴）、保底窗口截图、复制出的诊断文本、日志目录截图、设置页截图。

### T-34 首次连接不需要数字码（R-34，P0）

- **前置**：两台全新用户目录的机器，均未登录账号。
- **步骤**：① 从安装到连上完整走一遍，逐步记录是否出现任何数字码输入；② 开启无人值守并设配对码，用错误码连一次、正确码连一次；③ 连续输入 10 次错误码；④ 被控端重置配对码后再连。
- **判据**：默认路径全程无「配对码/验证码」输入步骤（录屏 + 步骤清单）；无人值守下错误码被拒且审计含 `pair_code_rejected`；协议证据显示配对字段在**独立包类型**内；10 次错误后锁定，锁定期内正确码也被拒；重置后旧码立即失效。
- **证据**：连接全程录屏、步骤清单、审计片段、开发提供的包结构说明、锁定与重置前后截图。

### T-35 黑屏原因提示（R-35，P1）

- **前置**：被控端为台式机，可物理关闭/断开显示器。
- **步骤**：① 关闭被控端显示器电源后发起连接；② 记录提示出现耗时；③ 恢复显示器后重连；④ 全局检索文案。
- **判据**：控制端 ≤3 秒出现提示，文案含「被控端显示器已关闭或无显示器」与「保持显示器开启」；不出现静默纯黑；恢复后重连画面正常且日志记录断开/恢复时间点；文案无「已自动修复」「已启用虚拟屏」「无需显示器」。
- **证据**：两端录屏、提示截图、日志时间点、文案检索输出。

## 3. 不做项的反向检查

| 用例 | 检查内容 | 判据 |
|---|---|---|
| T-OUT-01 | 中继服务与自动回退 | 默认配置无中继连接；中继关闭时失败不回退；无服务器地址内置 |
| T-OUT-02 | 移动端/Linux/macOS | 下载页与客户端无可点击的“即将支持”入口；文案明确仅 Windows |

## 4. 执行顺序与通过标准

### 4.1 建议顺序

1. **P0 冒烟**：T-33、T-34、T-01、T-02、T-03、T-04、T-05、T-08、T-09、T-10、T-11、T-13、T-16、T-17、T-21、T-27、T-28、T-29、T-31。（T-33 最先执行：主窗口显示不出来时，其余用例均无环境可测）
2. **P1 功能**：T-06、T-07、T-12、T-14、T-15、T-18、T-19、T-20、T-22、T-23、T-24、T-26、T-30、T-35。
3. **反向检查**：T-OUT-01 ～ T-OUT-08。
4. **后置**：T-25、T-32 仅在对应需求排期后执行，不计入 v1 放行。

### 4.2 放行标准

- 19 条 P0 需求全部通过；14 条 P1 中不允许有 S1/S2 缺陷未关闭。
- 反向检查全部通过；任一项命中即视为范围越界，退回产品确认。
- 所有用例有证据，无“口头通过”。
- 不支持环境不参与判定：iOS 真机记 N/A，企业策略拦截记 BLOCKED，二者不计 PASS/FAIL；不得用“换环境后能跑”替代原判据。
- 允许存在已登记的 S3/S4 缺陷，但必须写明影响与规避方式。

### 4.3 缺陷分级

| 级别 | 定义 | 例子 |
|---|---|---|
| S1 | 阻断连接、数据/安全风险、违反产品承诺 | 默认允许被连；退出后仍可被连；中继静默回退；出现付费入口 |
| S2 | 主要功能不可用或判据明显不达标 | 邀请串无法解析；停止后会话不断；旧版无法互连 |
| S3 | 有替代路径，但体验受损 | 状态条更新慢于 1 秒；缩放轻微错位 |
| S4 | 文案、样式、非关键提示 | 说明文字不通顺；图标间距不一致 |
