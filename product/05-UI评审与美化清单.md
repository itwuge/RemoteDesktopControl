## 1. 总体判断（5 条）

1. **骨架是对的**：上下单栏、分组框、标签在上、条目后置按钮、状态用按钮——与既定偏好一致，不需要推翻重做。
2. **最大问题不是“不好看”，而是“不像成品”**：首屏、屏幕墙、控制页、设置页底部都直接暴露了 `Rust/Flutter/DXGI/哈希/回环/设置文件路径`。普通用户第一眼会判断“这是开发工具”，而不是“能托付的远控”。
3. **第二问题是“安全状态不可见”**：首页看不到“我现在能不能被连、谁在连、一键停止”。真正的开关藏在两层之后（设置 → 远程访问权限），与痛点 TD-02 正面冲突。
4. **一致性是“局部统一、边界失守”**：页面内按钮 36px 统一，但弹窗沿用 Material 默认（按钮 40px、圆角 28、浮标签），权限页又整体换成“独立 AppBar + 900px 宽”，与其余页面的 1100px 无标题布局割裂。
5. **我们比 ToDesk 更“克制”，但缺了消费级标配**：没有付费/活动是对的；但设备码邀请、首启允许/拒绝、托盘与关闭语义、恢复默认、检查更新这些“日常必需”还没有。

**当前元素**
- 独立路由：`Scaffold + AppBar(title 18px)` + `maxWidth: 900`（`permission_page.dart:1027-1034`），与其余页面（无 AppBar、1100 宽）不同。

## 4. 竞品对照（ToDesk 5.2.3.0 实测记录 + 向日葵/RustDesk/AnyDesk/TeamViewer 公开资料）

> 来源：`product/01-消费者痛点清单.md`（ToDesk 实测 TD-01…TD-15；其余为公开资料）。本节只做判断，不抄布局。

### 4.1 我们缺什么（消费级标配，按用户价值排序）

### 4.2 我们比人家差在哪

1. **首屏任务不聚焦**：ToDesk 至少有“我的设备码/临时密码”，一眼知道“别人怎么连我”；我们首屏只有 4 个入口 + 3 个工程指标。
2. **设置项没有“什么时候需要它”**：ToDesk 至少给真彩/隐私屏这类开关一句解释（虽然有 17 项快捷键）；我们的“中继/降级/方向”比 ToDesk 更抽象，却解释更少。
3. **术语密度高**：`令牌/指纹/世代/接管/kind/action` 比 ToDesk 的“真彩/极速刷新”更难懂，因为后者是营销词，前者是安全工程词。
4. **弹窗体系落后于页面体系**：页面已经建立了 36/16/24 的规范，弹窗退回 Material 默认（40/28/浮动标签）。

### 4.3 人家做得笨拙、我们可以做得更好的地方（差异化清单）

| 竞品的笨拙 | 我们的机会 | 落地动作 |
|---|---|---|
| ToDesk 标题栏 9 个图标、无文字（TD-06） | 我们所有动作都有文字按钮 | 保持；补 Tooltip 只给“ID/指纹”这类必须缩写的字段 |
| ToDesk 关闭窗口后“是否还能被连”说不清（TD-09） | 关闭弹三选 + 托盘常驻状态一句话 | A6 |
| ToDesk 场景切换会换整套导航（TD-14） | 我们无场景 | 不做；用“能力矩阵”页承担“不同用法”解释 |
| ToDesk 屏幕墙是独立窗口（TD-11） | 我们已内嵌为页面 | 保持；补跨机接线后空状态示例 |
| ToDesk 升级入口在 3 处、活动弹层（TD-12/SF-06） | 我们零营销 | 保持；只保留“关于→检查更新” |
| ToDesk 临时密码可刷新但不说旧密码失效（TD-03） | 邀请文案里直接写“有效期 + 旧码立刻失效” | 邀请弹窗（新增） |
| ToDesk 17 项快捷键无解释（TD-10） | 只暴露 5 个高频快捷键 + “为什么用它” | 后置；先不做快捷键页 |
| RustDesk 首启不强制选择（RD-03） | 首启 1 屏 2 选 + 默认拒绝 | 新增 `FirstRunPage` |
| RustDesk 直连/中继不可见（RD-01） | 会话 HUD 写“直连 12ms / 中继 88ms” | D8 |
| TeamViewer 商业用途误判（TV-01） | 我们无判定、无账号强制 | 保持，并在“能力与限制”写明“不按用途封禁” |

## 7. 建议实施顺序与验收判据

### 7.1 顺序（每步独立可回滚，不合并主干）

5. **S5 消费级补全**（P1-14/17/18 + P2）：启动与托盘、首启、关于/更新、密码框、字体与缩放。

### 7.2 可量化验收（每步都要留日志/截图）

| 判据 | 通过标准 |
|---|---|
| 开发痕迹清零 | 全界面 grep 无 `Rust|Flutter|DXGI|纹理|回环|待接线|\.json|hash|SHA`（“关于→高级”例外） |
