### 本项目补充条款（R-T 层面，待经验库收编）

> 以下为项目侧补充，按第 14 行「仓库内只更新编号清单与差异记录」的约定记录于此，不复制经验库正文。

**R-T-11 一个工作树只归一条线使用。**

- 一个 worktree 同一时间只能检出并服务一条线；需要新职责时，**开新 worktree + 新分支**，不得在主工作树里换分支承接另一条线。
- 主工作树（`RemoteDesktopControl`）归可观测性线独占，其他线一律使用各自的 `RDC-*` worktree。
- 分支归属以本项目分支表为准，各线不得自行合并到 `master`，合并由指挥在阶段节点统一执行。
- 违反表现的判定：同一工作树内出现两条线的提交、或一条线切走了另一条线正在使用的分支，即视为违反本条款，当天按 R-T-4 记入事故。

分支归属表：

| 路径 | 分支 | 归属 |
|---|---|---|
| `RemoteDesktopControl`（主工作树） | `observability` | 可观测性线独占 |
| `RDC-render-fallback` | `fix/rdr-fallback-window` | Windows 主线 |
| `RDC-docs` | `docs/requirements` | 产品/消费者/需求文档 |
| `RDC-ui` | `ui-polish` | UI 整改线 |
| `RDC-android` | `android-client` | 安卓线 |
| `RDC-linux` | `linux-x11` | Linux 线 |
| `RDC-release` | `feature/auto-update` | 自动更新线（暂未投入，见 D55） |
| `master` | `master` | 指挥统一合并，各线不得自行合并 |
