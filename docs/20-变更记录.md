# 20 · 变更记录

> 用途：记录“谁在哪条线上改了什么、怎么验证的”，是门禁 R-T-4 的判定依据。
> 与 `17-经验与坑.md` 的边界：17 记可复用经验与坑，20 只记改动流水；不要把教训写进来。
> 门禁配置：`gate.config.json → team.changeRecordGlobs = ["docs/20-变更记录.md"]`。

---

## 1. 填写规则（强制）

1. **触发条件**：一次提交只要改动了 `team.sourceGlobs` 覆盖的源码（Rust/Dart/C++/C），就必须在本文件新增一行，并在同一次提交里完成。
2. **六个字段必填**：日期 / 分支 / 改了什么（一句话）/ 判据或测试计划 / 验证结果 / 提交 hash。
3. **验证结果必须真实**：写实际跑过的命令与结论；没跑就写“未跑 + 原因”，不得留空、不得写“应该没问题”。
4. **提交 hash**：用 7–9 位短 hash。提交时无法自指的就写 `待回填`，并在下一次提交补齐；不允许永远留 `待回填`。
5. **只追加，不删除**：修正旧记录用新增一行并注明“更正 <hash>”，保留历史。
6. **违规判定**：改源码而未动本文件 = R-T-4 违规；文件存在但没有对应的新增行，同样视为未填。
